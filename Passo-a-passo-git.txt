Primeiro passo:
- Instalar o git através do link (https://git-scm.com/install/windows)

Segundo passo:
- Abrir qualquer terminal em qualquer IDE

Terceiro passo:
- Rodar comando "git version" para validar de o git foi instalado corretamente

Quarto passo:
- Criar uma conta no github (https://github.com/)

Quinto passo:
- Criar repositório no github (Público ou Privado)

Sexto passo:
- Clonar o projeto através do seguinte comando 

git clone https://github.com/JonathanDSLima/Aulas-Web-SI.git

Sétimo passo:
- Adicionar alterações, arquivos, imagens, projetos e etc dentro do projeto clonado do github

Passo opcional:
- Rodar o comando "git status" para ver arquivos alterados

Oitavo passo:
- Através do comando "git add ." vamos adicionar todas as alterações

Nono passo:
- Commitar as alterações feitas no oitavo passo

Décimo passo:
- Rodar o comando "git commit -m "texto referente as mudancas adicionadas"" ex:

git commit -m "Subindo pastas das aulas 1 a 6"

Décimo primeiro passo:
- Subir os commits feitos, através do comando "git push origin main" ou "git push origin master"
ex: git push origin main

Obs: Para o seguinte error (fatal: the remote end hung up unexpectedly) use o comando (git config --global http.postBuffer 524288000)

Comandos mais importantes:
git clone nomeprojeto
git status
git add .
git commit -m "Texto do commit"
git push origin main (ou nome da branch que vc está)


Segundo passo:
- Fazer todos os comandos de git add, git commit, git push até subir a branch nova no github

Terceiro passo:
- Transitar entre as branchs com o comando "git checkout nomeBranchExistente"
